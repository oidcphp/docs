# oidcphp documentation

User documentation of [oidc/core](https://github.com/oidcphp/core), the OpenID Connect Relying Party library for PHP.

Published at https://oidcphp.oauth2.tw/.

## Development

```sh
npm install
npm run dev     # http://localhost:4321/
npm run build   # output in dist/
```

Pages are Markdown files in `src/content/docs/`. The site is built with [Starlight](https://starlight.astro.build/).
