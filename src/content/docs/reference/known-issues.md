The goal of the library is to follow the specifications exactly. These behaviors of the current version do not, and are tracked as issues.

| Issue | Behavior | What to do now |
| --- | --- | --- |
| [#14](https://github.com/oidcphp/core/issues/14) | ID Tokens with `alg=none` are rejected, even when the client registered `none` | Use a signed ID Token |
| [#15](https://github.com/oidcphp/core/issues/15) | The values given to `handleCallback()`, except `nonce`, are sent to the token endpoint and copied into the `TokenSet` | Only give `state`, `nonce` and `redirect_uri` |
| [#16](https://github.com/oidcphp/core/issues/16) | `Issuer::discover()` does not append the well-known path | Pass the full `/.well-known/openid-configuration` URL |
| [#18](https://github.com/oidcphp/core/issues/18) | `LogoutTokenVerifier` does not validate `exp` | |
| [#21](https://github.com/oidcphp/core/issues/21) | `Issuer::discover()` does not validate the `issuer` of the configuration | Only discover trusted providers from a URL you configured |
| [#20](https://github.com/oidcphp/core/issues/20) | `client_secret_basic` does not form-urlencode the credentials | Avoid special characters in `client_id` and `client_secret`, or use `client_secret_post` |
| [#22](https://github.com/oidcphp/core/issues/22) | `client_secret_post` appends a NUL character to the request body | |
| [#23](https://github.com/oidcphp/core/issues/23) | Form bodies use RFC 3986 encoding instead of `application/x-www-form-urlencoded` | |
| [#43](https://github.com/oidcphp/core/issues/43) | `createAuthorizeFormPostResponse()` and `initiateLogoutFormPostResponse()` do not escape parameters in the generated HTML | Use the redirect variants, or never pass user input as a parameter |

Also note:

- `nonce` is generated by `initAuthorizationParameters()` but not added to the Authentication Request. Pass `'nonce' => $client->getNonce()` yourself.
- An error response at the callback raises `'code' missing from the response`, see [Handling the Callback](/guides/callback/#error-responses).

See all [open issues](https://github.com/oidcphp/core/issues).
